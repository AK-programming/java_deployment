# java_deployment_Steps
1) Spring Boot and Maven build
2) Dockerfile, image building and containers
3) AWS IAM, EC2 and ECR
4) Docker authentication, image tagging, pushing and pulling
5) Deploying the application on EC2
6) Nginx reverse proxy and configuration
7) Security Groups and network security
8) GitHub Actions CI workflow
9) Planned CI/CD with OIDC and AWS Systems Manager

java Application build ----> Dockerize ----> Automate(CI/CD) ----> push image to ECR ----> Pull in EC2 ----> Deploy on EC2 -----> Reverse Proxy(Nginx) ----> Public Link -----> DNS
